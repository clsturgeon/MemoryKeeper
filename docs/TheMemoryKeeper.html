The Memory Keeper is a personal research tool designed to help genealogists and other researchers capture research data, track progress, and draw conclusions based on evidence to create compelling narratives.

Welcome to The Memory Keeper, a personal research tool powered by TiddlyWiki. The Memory Keeper enables you to capture and track evidence-based research projects. From the evidence collected the researcher can create proof statements, summaries, and arguments to draw conclusions.

The Memory Keeper provides solutions for various types of research, with a primary focus on the needs of genealogists. It can also be used for other research projects. You may find the Memory Keeper can track much more, including student studies.

This online document includes detailed reference material, how to instructions, and free downloads. This documentation is not a webpage or a collection of webpages. Rather, the document you are viewing is an instance of the Memory Keeper configured with documentation content and examples of how to use it for various projects. Therefore, the examples are real. Real in that you can also edit and experiment with the content and configuration.

The Memory Keeper is an open source TiddlyWiki solution that enables users to capture sources, generate source citations, collect evidence from each source, and create research assertions (proofs). These assertions lead to conclusions, the people, the events, the places, and the organizations. Ultimately, the reader is presented with sound conclusions supported by evidence from a variety of sources. Those who fail to use a historical method, making assertions without capturing evidence, will produce weak narratives.

Memory Keeper does not dictate the use of any particular historical method, or require any particular order of steps. You can create person, event, place and organization entries without providing any sources, evidence, or writing an assertion.

The Memory Keeper provides a "research score" for your conclusions, acting as a guide of your progress. If assertions are not based on evidence from sources, the research score will be low. The purpose of the score is to encourage the user to provide more proof. The score is not a measure of the quality of your claims. The score will also factor in the type of sources used, giving higher scores to primary sources rather than narratives.

The Memory Keeper empowers its users to create various kinds of entries such as person, event, and place entries. This tool also facilitates researchers to compose books, articles, and research papers. Its primary aim is to provide a non-linear mode of viewing, reviewing, and editing the information. For instance, while exploring a person's entry, one can also access details about their immediate family members, events associated with them, the location of those events, and all the supporting sources, evidence, and assertions. Additionally, one can examine a list of papers and chapters that an individual has been referenced.

Uses of The Memory Keeper
Memory Keeper is ideal for:
- historical researchers
- genealogists
- photographers
- students
- authors

The Memory Keeper can be used for writing. Fiction and non-fiction writers can develop their characters (people), settings (locations), and events (scenes). Writers can draft an entire novel within its platform. As the writer composes different chapters, Memory Keeper can report where characters, settings, and scenes appear in your writing.

"Memory Keeper" and the "Genealogical Questionnaire" are open-source projects and are available for free. See license for more details.

There is no software to install. You download a single HTML file. Open the HTML file in a browser. The HTML file is self-modifying. Users add and edit the content in the browser and save the modified content back to disk. Create project content in a dedicated folder structure on a local computer disk and transfer the content to removal media for backups or sharing with others. Ideal for professional genealogists. Supply clients removal media that is complete without any software to install.

This instance of The Memory Keeper has additional TiddlyWiki (TW) plugins that are not included with the default Memory Keeper. You can easily drag and drop plugins from one instance to another, so you can take advantage of these plugins. This instance also has a large collection of MK addons you may want. There are multiple ways to navigate this instance. You could navigate the documentation, the reference material below. You'll also want to use the menu items on the Content tab on the side bar. This is a working or otherwise an interactive demonstration instance of the Memory Keeper. You can view how sources, evidence, assertions (proofs), people, events, places, organizations, etc. can be added and managed. You add content to this working instance. You can remove entries. You can edit content. You could reconfigure the look. What you cannot do is save your content back to the server. To restore the original content in the browser simply refresh/reload the page from the Internet.

You can save your creation back to your computer (but without the source documents and images). A better way to experiment with your own images and source documents is to download the Memory Keeper. There is no software to install, and therefore, works on multiple platforms. You download an HTML file, open in your favourite browser (yes, you can do this) where you view and manage the content, and save on your computer, keeping the content secure on your computer, not on the Internet. It is open source, free to use.

Considerations

The Memory Keeper (MK) includes typical data entities that are included with other genealogical applications. However, here is short list of things to consider:

  • Events are shared (any individual can be assigned to an event)
  • People associated with an event can have a role defined in the event
  • Events can be associated with people, places, organizations. It is not mandatory an event be associated with a person.
  • Events can have a parent event (an event that occurred, occurred during a greater event) which makes for interesting person timelines. Since events are nested, timelines are nested and interactive.
  • Users can define custom event types
  • Places can have a parent place (Eg. a cemetery plot is located in a cemetery. The cemetery is located in a city, that is located in a county, that is located in a province, etc.)
  • Users can define custom place types
  • Places can be drawn on a map. Numerous map layers are available (street and satellite maps). E.g. define cemetery plots for a given cemetery to autogenerate a map of burials.
  • Capture business and military organizations
  • Capture founding and closing dates of organizations. Define organizational members with start and ending dates to autogenerate organizational timelines. Ideal for business and military research.
  • Users can define custom organization types
  • Capture Indigenous Nations, cross referencing people, events, etc. with Indigenous Nations.
  • Capture and track alliances, grouping people, organizations, countries and Indigenous Nations.
  • Define projects and tasks and associate all the people, events, places, sources, evidence, assertions (proofs), notes, contacts, research resources, and more to create a collections of organized research based on specific project
  • Go off-road. Like FAN (Friends, Associates & Neighbours), research the people, events, organizations, and places behind the stories of your ancestors. Off-road is a deep dive beyond FAN. Create off-road projects and tasks (see point above).
  • Projects and tasks can also be used to build networks, how people, places, events, organizations, sources are related based on a specific topic
  • Tasks can be further defined as an appointment or a fact check (research and capture family folklore)
  • Users can define their own custom task types.
  • Generate reminders and post notes.
  • Autogenerate a timeline from assigned events to projects and tasks
  • Write research papers and an e-book in MK. Cross reference people, events, places, etc. with your writing, enabling to you list all chapters a given person, event, or place is referenced in your writing.
  • Track your research in a personal research journal. Cross reference all people, events, places, sources, etc with your journal entries.
  • Track your physical copies of sources and photographs (Personal Archive).
  • Track DNA matches
  • Create citations for sources. Citations can be reused in your e-book. Autogenerate bibliographies.
  • Capture sources, including PDF documents and images of source documents.
  • Sources can be cross referenced to people, events, places, etc.
  • User can define their own custom transcription data field for source documents.
  • Users can define their own custom source types.
  • Create table of contents for PDF documents. Enables the user to jump to a specific page in the pdf file.
  • Track your research resources. This includes literature, learning-aids, research databases, research repositories, and references. These can be cross referenced with research journal entries and sources.
  • Associate photographs with people (in the image), the events (associated with the image), the place (where the image was taken), and a number of other MK entities.
  • Capture evidence found in source material. Do not comment on evidence, just capture it. Assertions are used for your opinion.
  • Capture Assertions, detailed proof statements, summaries and arguments based on the evidence captured.
  • Identify the photographer and camera equipment used for photographs.
  • Tag faces in an photograph adding a photo map to photograph. Enables user to click on a face to open a person's tiddler.
  • Include audio and video clips, associating these with the people, events, places, etc.
  • Create table of contents for audio clips. Enables user to jump/skip to specific time in the clip.
  • Track important physical objects and vehicles (including the passenger ships your ancestor travel on), cross reference these entities with crew, passengers, events, etc.
  • Capture your collection of definitions, including causes of death, languages, military ranks, and occupations.
  • User and define custom definition types.
  • Capture quotes. As like other entities, quotes can be cross referenced with people (in the quote), events, places, and sources.
  • Capture datasets, raw data sets that can be graphed. E.g. population data of a place.

Reference Material

General Concepts
General concepts to help the user understand how to use The Memory Keeper.


Research
Research content is a collection of sources, evidence, research assertions, research journals, research tools, research resources, charts, trees, and project management entities.


Indigenous Research
The Memory Keeper supports Indigenous Nations research.


Conclusions
Conclusions are captured as people, events, organizations, places, and objects. This is not to be confused with "assertions" which are proofs. The conclusions listed above can be associated with each other and research entities such as sources, tasks and projects where it makes sense to do so.


Supporting Data
Supporting data entities provide exactly that, data that supports research and conclusions.


Authorship
The purpose of the Authorship Content in MK is to capture definitions, quotes, and your written work. Do not use the Authorship content for other author's works.
